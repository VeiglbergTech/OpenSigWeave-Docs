---
title: "Restore an earlier signature"
description: "Non-destructive recovery of signature content"
---

Choose an existing version in the **Signatures** version history and use the restore action. The application creates **another new current version** containing the historical HTML. It does not erase intervening versions.

After restoring, check the preview, public image URLs, domain scope, group selection and send a staging test. This is different from restoring a full system backup.

For disaster recovery after data loss, see [Backup restore](/operations/restore/).
