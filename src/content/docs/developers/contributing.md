---
title: "Contributing"
description: "Where to propose changes and report issues"
---

Open a GitHub issue or pull request against the relevant repository. Implement application changes in [OpenSigWeave](https://github.com/VeiglbergTech/OpenSigWeave) and documentation changes in [OpenSigWeave-Docs](https://github.com/VeiglbergTech/OpenSigWeave-Docs).

Keep the code behavior and documentation synchronized, describe verified behavior separately from planned work, and avoid including passwords, tokens, internal IPs or private audit materials.

Application changes follow `dev → beta → main` with tests and manual release authorization. Documentation uses its own `dev → main` verification and automatic promotion gate; the approved site is published through GitHub Pages. Consult the [application repository contribution guidance](https://github.com/VeiglbergTech/OpenSigWeave/tree/dev).
